# مُعين v1.7 — مساحة المبرمج العربي — محلي أولًا


## ما تم إصلاحه وتحسينه

- إزالة شاشة تسجيل Google الإلزامية من صفحة الأدوات البرمجية؛ المحادثات تحفظ محليًا في المتصفح.
- دعم العربية والإنجليزية في الردود الأساسية.
- إضافة ردود ترحيب وسلام وشكر أكثر طبيعية.
- إضافة إجابات مباشرة لعواصم مجموعة واسعة من الدول بالعربية والإنجليزية.
- رفع صور وملفات نصية وبرمجية من الهاتف عبر زر **إرفاق ملف**.
- تحويل الملف النصي أو البرمجي إلى بطاقة معرفة محلية قابلة للبحث، مع حد 4MB لكل ملف.
- إبقاء الخدمات السحابية اختياريًا عبر خادم لا يكشف المفتاح للمتصفح.
- تنظيف تجربة الدخول القديمة والاعتماد على جلسة محلية واضحة.

## التشغيل على الكمبيوتر أو الهاتف

للتجربة المحلية على الكمبيوتر:

```bash
python3 -m http.server 8080
```


## كيف تغذّي مُعين من الهاتف

افتح صفحة الأدوات البرمجية، اضغط **إرفاق ملف**، اختر ملف TXT أو Markdown أو JSON أو CSV أو HTML أو CSS أو JavaScript أو Python أو SQL، ثم اكتب سؤالك واضغط إرسال. يُحفظ محتوى الملف محليًا في قاعدة المعرفة. من لوحة **تدريب** يمكنك إضافة سؤال وجواب يدويًا، ومن **تصدير المعرفة** حفظ نسخة JSON ونقلها أو الاحتفاظ بها كنسخة احتياطية.

## الفحص

```bash
node --check app.js
```
